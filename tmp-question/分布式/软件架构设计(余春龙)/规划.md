# 余春龙《软件架构设计》— 解读计划

## 全书概况

| 属性 | 数值 |
|------|------|
| 出版 | 2019年2月，电子工业出版社 |
| 篇幅 | 3,449行 (OCR优质，仅1个乱码字符) |
| 结构 | 5部分 17章 |
| 作者背景 | 阿里巴巴技术专家力荐，腾讯工程师力荐 |

## 本书独特定位

**这不是又一本分布式技术书。** 8 本已完成的参考书全是"硬功夫"（共识算法、高并发、分库分表）。余春龙是唯一一本系统讲**架构方法论**+**业务架构**+**技术管理**的书。

全书 17 章可以分为三个层次：

```
心态层（Ch1-2）：架构师是什么？怎么思考？
  ↓
能力层（Ch3-12）：计算机功底 + 技术架构 ← 与其他书重叠最多
  ↓
价值层（Ch13-17）：业务架构 + 技术管理 ← 本书独特价值
```

## 章节结构与拆分方案

| Ch2 | 架构的道与术 | 抽象思维、方法论、道法术器 |

| 章 | 内容 | 原始篇幅 | 策略 |

| Ch3 | 语言 | 51行 | 概述即可 |

| Ch5 | 网络 | **652行** | 同上，只讲生产相关（TIME_WAIT、长连接、网关） |
| Ch6 | 数据库 | **964行** | 同上，只讲架构层面（索引原理、SQL优化方法论） |
| Ch7 | 框架/中间件 | 46行 | 概述 |

### Part 3: 技术架构之道（Ch8-12, ~?行）

| 章 | 内容 | 与已有书的覆盖 |
|----|------|------|
| Ch8 | 高并发问题 | 唐扬《高并发》已深度覆盖 |
| Ch9 | 高可用与稳定性 | 王伟峰《高可用》+ 高翔龙 Ch3 已覆盖 |

**Part 2-3 的处理策略**：不是复述技术细节（其他书已经做了），而是提取**"架构师视角"**——一个架构师在这些领域必须知道什么、到什么深度、与其他角色的分工。

## 写作重点

### 与其他 8 本已完工书的关系
- 技术细节不重复，用 `参见 XXX 书第X章` 引用
- 重点回答："架构师和高级工程师在这些领域的区别是什么？"

### 本书独家内容（重点展开）
- 道法术器的架构方法论
- DDD 限界上下文与微服务拆分的对应关系
- 技术架构如何跟随业务架构演变
- 从技术到管理的转变路径

### 2026年补充视角
- 原书 2019年 — 补充 AI/Copilot 时代架构师的角色变化
- DDD 在云原生时代的实践（Event Storming + Serverless）
- 团队管理在远程工作时代的调整
