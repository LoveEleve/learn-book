## 一、Q9 回答:三种模式共享同一内核(已证实)

**证据链**:
1. `interactive-mode.ts:392` — `private runtimeHost: AgentSessionRuntime`(InteractiveMode 持有运行时)
2. `print-mode.ts:33` — `runPrintMode(runtimeHost: AgentSessionRuntime, ...)`(print 模式同样注入)
3. `rpc-mode.ts:54` — `runRpcMode(runtimeHost: AgentSessionRuntime)`(rpc 模式同样注入)
4. `agent-session-runtime.ts:74` — `AgentSessionRuntime` 类:session + services + rebind/beforeInvalidate 回调 + **扩展事件桥**(session_before_switch/session_before_fork 可取消钩子)

**结论**:interactive/print/rpc 三模式 = AgentSessionRuntime 的三种外壳,共享全部会话/压缩/工具/扩展逻辑。
**产品映射**:产品②执行引擎的"多形态"(交互/自主/协议驱动)只需换外壳,内核不变——与 Hermes 的"同一 AIAgent 跑 CLI/gateway/TUI"同构,这是 agent 项目的通用模式。
