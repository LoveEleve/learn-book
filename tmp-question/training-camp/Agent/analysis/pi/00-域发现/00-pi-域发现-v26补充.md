## 二、关键设计(通用价值)

1. **"上下文分层 + 遮蔽检测"**:全局 → 祖先 → 项目,最内层遮蔽最外层——**上下文注入的优先级规则**(与 settings 双作用域合并互补:settings 是合并,context 是遮蔽)
2. **"全覆盖 override"**:所有资源可被嵌入方改写——**可测试性/可嵌入性的关键设计**(与 Hermes system prompt override、Reasonix agentpreset 同思想)
3. **"精确禁用开关"**:no* 开关——**最小加载**

**产品①对齐模块映射**:resource-loader 是"A 档入口自发现"的完整参考:
- 上下文文件分层(项目 AGENTS.md 遮蔽全局)= 对齐时"哪些指令生效"的规则
- override 钩子 = 测试/嵌入时注入规格书模板
- no* 开关 = 精确控制加载
