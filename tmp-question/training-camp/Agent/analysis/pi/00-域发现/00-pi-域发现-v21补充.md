## 二、关键设计(通用价值)

1. **"disposal 使子句柄失效"**:父连接释放 → 所有派生的句柄/请求立即失效——**生命周期级联的正确性**
2. **"拒绝有损转换"**:协议映射拒绝信息有损的转换(外来 tool id/非法源 id)——**协议严格性**(与 reducer 拒绝损坏同哲学)
3. **"广播只给附加客户端"**:会话事件只发附加的客户端,不广播全局——**事件路由的正确性**
