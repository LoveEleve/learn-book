## 二、关键设计(通用价值)

1. **"快照代际检查"**:异步刷新结果用 seq 校验,过期丢弃——**异步一致性的代际模式**(与 Hermes SessionStore routing_generation、Reasonix uihub 代际隔离同族——三项目共证)
2. **"凭证操作串行化"**:每 provider 的凭证写串行(前一完成后才下一)——**凭证竞争的正确性**
3. **"错误包完整诊断"**:CredentialSynchronizationError 携带 providerId/operation/credential/cause——**失败可诊断**
4. **"凭证同步链路"**:改凭证 → recompose → refresh → 快照更新 → 可用性刷新——**变更传播的完整链路**
