## 二、关键设计(通用价值)

1. **"provider 兼容 = 测试即契约"**:137 个测试定义"各 provider 必须怎样行为"——**多 provider 产品的兼容性靠测试套件锁定**(与 Hermes transports 测试、Reasonix provider 测试同思想)

3. **缓存亲缘 e2e**:缓存命中的端到端验证——**prompt 缓存的正确性需要真实验证**
