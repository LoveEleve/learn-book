## 二、关键设计(通用价值)

1. **"原子发布"三项目对比**:Pi 临时文件+rename ↔ Hermes atomic_write_text ↔ Reasonix fileutil——**"完整临时文件+原子 rename"是写正确性的通用实现**(崩溃只留 .tmp)
2. **"类型白名单解码"**:解码时未知类型拒绝(不是忽略)——**解析严格性**(与 reducer 拒绝损坏、协议拒绝有损转换同哲学)
3. **"内存后端共享状态机"**:InMemory 与 SQLite 共享 applyMutation——**多后端共享行为规范**(conformance 工厂的根基)

**产品④知识库映射**:jsonl 存储(原子发布+类型白名单)就是"知识库日志文件"的直接实现参考——追加写 + 原子发布 + 严格解码。
