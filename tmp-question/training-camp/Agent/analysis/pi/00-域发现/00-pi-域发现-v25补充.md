## 二、关键设计(通用价值)

1. **"只写改过的字段"**:修改追踪 → flush 只写变更——**部分写入优化**(与事件溯源"增量日志"同思想)
2. **"双作用域合并"**:全局默认 + 项目覆盖 + **项目不可信不加载**——**配置分层 + 信任门控**(对齐模块 6 维盘问的默认值来源参考)
3. **"迁移先于读取"**:旧格式设置自动迁移——**配置兼容性**
4. **"解析错误显式记录"**:加载错误不静默(后续可诊断)

**产品①对齐模块映射**:settings-manager 的"双作用域 + 修改追踪 + 迁移"正是规格书持久化的参考——全局默认(方法论默认值)+ 项目覆盖(用户画像)+ 只写变更(知识库增量)。
