## 二、跨项目印证(新增)

1. **资源优先级仲裁**:Pi resourcePrecedenceRank(package>project>user)↔ Reasonix pluginpkg manifest(来源分级)↔ Hermes 技能 hub 信任矩阵——**"同资源名冲突时的确定性仲裁"是通用需求**
2. **headless 协议**:Pi rpc-mode(JSON stdin/stdout)↔ Hermes ACP/tui_gateway(JSON-RPC)↔ Reasonix acp/eventwire——**无界面运行形态三实现**
3. **stdout 背压**:Pi output-guard(ENOBUFS 重试)↔ Hermes stream_single_writer——**协议输出不损坏的通用工程**
4. **schema 单一真相源**:Pi TypeBox schemas ↔ Hermes SCHEMA_SQL ↔ Reasonix extension protocol generated——**协议/存储 schema 单一真相源三实现**
