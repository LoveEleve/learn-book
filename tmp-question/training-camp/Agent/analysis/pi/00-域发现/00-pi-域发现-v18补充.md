## 二、关键设计(通用价值)

1. **"扩展抛错 → 回退默认"**:自定义压缩失败时静默回退默认实现——**扩展点必须有默认回退**(与 Reasonix 扩展拦截超时回退同思想)
2. **"prompt 等待重试完成"**:重试是同步语义的一部分,不是异步旁路——**重试不改变调用方等待契约**
3. **"注册后刷新"**:动态工具注册后工具表刷新——运行时动态性
4. **"promptSnippet 缺失 → 保留但不出现"**:工具可用但不暴露给模型——**"注册 ≠ 可见"的分离**
