## 二、关键设计(通用价值)

1. **"会话恢复优先于配置"**:恢复的会话模型/思维级别优先——**跨 session 延续的正确顺序**(与 #21 交接同思想:上次的状态是默认)
2. **"恢复失败不静默"**:modelFallbackMessage 显式告知恢复失败——**降级必须可感知**
3. **"思维级别按模型钳制"**:模型不支持 xhigh → clamp 降级——**能力约束的运行时校验**(与 Hermes vision auto-detect 同思想)
4. **"默认四件套"**:read/bash/edit/write——**最小有用工具集**
