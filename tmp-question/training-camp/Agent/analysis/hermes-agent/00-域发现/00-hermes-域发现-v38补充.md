## 一、v38 深化确认

### moa_trace(182)

| 设计 | 要点 |
|------|------|
| **完整 MoA 回合追踪** | opt-in(moa.save_traces):每个引用模型收到的**确切消息数组**/完整输出/聚合器收到的确切数组(含注入的引用上下文指导块)——**端到端离线审计**(每个模型看到什么/说了什么/花费多少) |
| **侧通道设计** | **不是 messages 表,永不进消息历史/重放**(MoA 引用是 advisory 侧调用,有自己 system prompt,不是对话回合——作为消息行持久化会破坏角色交替/重放);独立文件按 session 键,可安全删除 |
| **默认关闭** | off 时只有 _traces_enabled() 配置读开销(无文件 I/O/序列化) |

**价值**:与 Hermes 可观测哲学一致(观测不污染主数据)——**"审计数据独立于主数据"**(与 Pi telemetry 敏感属性、Reasonix 侧车日志同族)。
