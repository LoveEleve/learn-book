## 一、v34 深化确认

|------|---------|
| **credential_files(566)** | 远程后端(Docker/Modal/SSH)文件透传注册表:凭证/技能目录/宿主缓存目录(**只读挂载**)+ 每次命令前重同步(Modal);凭证来自 skill 声明 required_credential_files——**远程沙箱的宿主文件桥** |

## 二、关键设计(通用价值)

1. **"变异使 refs 失效"**:浏览器 refs 只在最新快照可用,变异后必须重读——**引用失效协议**(与 checkpoint 代际、Reasonix uihub 同思想)
2. **"宿主文件只读桥"**:远程沙箱只读挂载宿主缓存——**沙箱安全(只读)**
