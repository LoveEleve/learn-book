1. 设计与开发 Agent 相关主线产品的关键特性,包括**内核框架、业务逻辑、效果调优**;

3. 关注业务数据与指标,围绕**模型效果与用户体验**做持续打磨;
4. 与模型、工具生态、前端、产品等团队协作,把优秀实践沉淀为**可复用的框架能力**;

1. 具备优秀的 AI Agent 产品与技术认知,深入理解 Agent 的产品形态、核心能力与落地路径,关注**模型效果、任务执行、工具调用与用户体验**;
