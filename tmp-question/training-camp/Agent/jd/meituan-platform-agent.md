# 美团 基础研发平台 AI Agent 系统 JD

> 来源:用户提供(2026-08-14)
> 岗位:Agent 系统架构设计与核心研发(规划推理/工具调用/记忆管理/多轮对话)

## 公司/部门背景

基础研发平台是美团的核心技术平台,立足于"零售+科技"战略,打造人工智能、大数据、云计算、安全等核心技术能力,以及研发效能平台、企业应用平台等公共服务。接触超规模集群、海量数据,挑战高复杂业务场景。

## 职责

1. 参与 AI Agent 系统的**架构设计与核心研发**,包括 Agent 的**规划推理、工具调用、记忆管理、多轮对话**等核心模块的设计与实现;
2. 围绕 **Prompt Engineering、RAG、Function Calling** 等技术构建稳定可靠的智能体应用;
3. 设计并实现 **Agent 编排框架**,支持**多 Agent 协作、任务分解与执行、异常恢复**等复杂场景;
4. 与业务团队紧密协作,理解业务需求,推动 AI Agent 在实际场景中的应用与迭代;
5. 关注行业前沿进展,调研并引入 Agent 相关的新技术、新范式,持续提升系统能力边界。

## 基本要求

1. 计算机科学、人工智能或相关专业本科及以上学历,3 年以上后端或 AI 工程开发经验;
2. 熟练掌握 **Python、Go、Java** 中至少一门语言,具备扎实的工程能力和良好的代码规范;
3. 熟悉大语言模型的工程应用,有 **LLM API 集成、Prompt 工程、RAG 系统开发**的实际经验;
4. 了解主流 Agent 框架的设计理念与使用方式,具备良好的系统设计能力,能够独立完成中等复杂度系统的架构设计与落地;
5. 良好的沟通协作能力和自驱力。

## 优先条件

1. 有完整的 **AI Agent 产品从 0 到 1 落地经验**,能够分享在实际业务中遇到的挑战及解决方案;
2. 具备 **Agent 安全性**方面的实践经验,包括 **Prompt 注入防护、权限控制、输出安全审核**等;
3. 有开源项目贡献经历,或在相关技术社区有持续的技术输出。

## 岗位亮点

深度参与 AI Agent 前沿技术的探索与落地;技术氛围浓厚,鼓励创新和技术分享;业务场景丰富且具有挑战性;扁平化管理。
