# 美团 基础研发平台 AI Agent 框架核心组件 JD

> 来源:用户提供(2026-08-14)
> 岗位:AI Agent 系统架构设计 + 核心组件开发(Planner/Executor/Evaluator)

## 公司/部门背景

基础研发平台是美团的核心技术平台,立足"零售+科技"战略,打造人工智能、大数据、云计算、安全等核心技术能力。接触超规模集群、海量数据,挑战高复杂业务场景。

## 职责

1. 负责 AI Agent 系统的架构设计与核心模块开发,包括**任务规划、工具调用(Tool Use / MCP)、记忆管理、多 Agent 协同**等能力建设;
2. 深度参与 **LLM 集成与推理链路优化**,研究 **Prompt Engineering、Function Calling、RAG** 等关键技术在生产环境的落地;
3. 设计并实现 **Agent 框架的核心组件(Planner、Executor、Evaluator)**,保障系统的**稳定性、可观测性和可扩展性**;
4. 与业务团队密切合作,将 Agent 能力落地到具体场景,推动从 **demo 到生产环境的全流程工程化**;
5. 持续跟踪 AI Agent 领域前沿进展,将有价值的技术方案引入团队。

## 基本要求

1. 本科及以上学历,计算机相关专业,3 年以上后端或 AI 工程开发经验;
2. 扎实的工程基础,熟悉 **Python / Java / Go** 至少一门;
3. 有 LLM 应用开发实际经验,熟悉 OpenAI / Anthropic / 主流开源模型的 API 使用,了解 **Function Calling、Tool Use** 机制;
4. 有 Agent 框架开发或使用经验(**LangGraph、AutoGen、CrewAI、或自研框架**),理解 **ReAct / Plan-and-Execute 等 Agent 范式**;
5. 熟悉 **RAG 系统设计**,包括向量检索、知识库构建、上下文管理等;
6. 有生产级 AI 系统落地经验,了解 **Prompt 版本管理、Trace/Log 可观测性、评估体系建设**等工程实践。

## 优先条件

- 有 **MCP(Model Context Protocol)协议开发或集成经验**;
- 有多 Agent 协同、**Agent 编排系统**设计经验;
- 对大数据或数据开发工具链有了解(了解即可,非必要);
- 参与过开源 Agent 项目,或有自己的相关作品。

## 岗位亮点

1. 参与前沿 AI Agent 技术研发,推动智能化应用落地;
2. 与高水平团队共同成长,提供广阔的技术发展空间。
