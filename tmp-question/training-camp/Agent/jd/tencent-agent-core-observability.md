# 腾讯 社交产品 AI Agent 岗位 JD(两份)

> 来源:用户提供(2026-08-14)
> 岗位 A:AI Agent 核心系统(规划/记忆/意图/多Agent/RAG/基建)
> 岗位 B:Agent 执行链路 tracing & observability + 质量评估体系

---

## 岗位 A:AI Agent 核心系统

### 职责

1. 设计并实现社交产品中的 AI Agent 核心系统,包括:**任务规划(Planning)、长期记忆系统(Long-term Memory)、意图识别与多 Agent 协同、RAG 架构与效果优化**;
2. 构建 Agent 基础设施,包括:**Durable Execution 长任务执行框架、沙箱与安全执行环境、Skills 编排与 MCP 协议集成**;
3. 建立**模型效果评测与优化飞轮**,推动效果持续迭代;
4. 跟进主流 Agent 框架并结合业务落地;
5. 参与**模型推理加速、微调与强化学习**等性能优化工作。

### 要求

1. 深刻理解 **Transformer 与 LLM 原理**;
2. 有 Agent 实战项目经验;
3. 扎实编程能力,熟练使用 AI 进行研发;
4. 良好的系统设计与工程能力。

### 加分项

1. 精通主流 Agent SDK 或多 Agent 框架;
2. 有模型微调 / 强化学习 / 推理优化经验;
3. 有高并发或分布式系统经验。

---

## 岗位 B:Agent 可观测性 + 质量评估体系

### 职责

1. 参与设计并实现 **Agent 执行全链路的 tracing & observability 系统**;
2. 参与构建 **Agent 质量评估体系**:自动化 eval pipeline、A/B testing、regression detection;
3. 开发 **Agent debugging 工具**;
4. 参与核心支撑平台(**标注、SBS 评测、数据管道**)的架构设计与开发;
5. 与 AI 研究团队零距离,将大模型与 Agent 协同进化的研究成果工程化落地;
6. 探索并实践 AI Agent 的日常工作流。

### 要求

1. 使用 **Cursor / Claude Code / Codex** 等进行重度编程,对 agentic coding 的能力边界和 **failure mode** 有切身的体感;
2. 极客精神,拥有一定的全栈工程能力和系统设计功底;
3. 熟悉 AI/Agent 技术栈,了解 **LLM、Agent framework、prompt engineering**;
4. 代码质量要求严格,代码是给未来的 AI 和人一起维护的,可读性、架构性缺一不可;
5. 对 Code Agent 的未来有深刻思考。

### 加分项

1. 有 Agent Observability 系统的开发或深度使用经验;
2. 参与过 AI Agent 产品从 0 到 1 的构建;
3. 开源项目贡献者 或 有趣的个人项目、技术博客;
4. 喜欢高密度协作和快速迭代的工作模式。
