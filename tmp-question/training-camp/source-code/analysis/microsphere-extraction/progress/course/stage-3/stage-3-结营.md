### 关键决策与权衡

| 决策 | 权衡 |
|------|------|
| 事故复盘（记录） vs 故障分析（根因） | 现场价值 vs 方法论价值（stage-3 18 才是本体） |

### 常见坑/反模式

1. **把事故当知识点**：事故是案例素材不是机制——知识本体在已提取篇目（引用不重提）
2. **复盘止于现场**：只有截图没有根因 = 无方法论价值（对照 stage-3 18）
3. **单点不设防**：本地单机无多活没问题，生产化必须面对基础设施单点（触发条件驱动）
4. **"无法持久化"绝对化**：session 默认内存不可持久 ≠ 无法持久（集中式 Session 是标准解法）
