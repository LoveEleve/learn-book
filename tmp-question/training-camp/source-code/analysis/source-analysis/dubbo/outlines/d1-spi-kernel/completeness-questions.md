# D-1 SPI 微内核 — completeness-questions (全视角提问验证)

## 开发者视角

1. 扩展怎么声明? (@SPI + 配置文件 name=类)
2. 加载目录? (3 个)
3. 默认扩展? (@SPI value)
4. 单例? (CHM 缓存)
5. 注入? (setter + 自适应对)
6. Wrapper? (包装器链)
7. 自适应? (URL 参数选)
8. 激活? (group/条件/order)

## 架构师视角

9. 为什么 URL 总线? (参数统一载体 — 扩展选择解耦)
10. 为什么动态生成? (无注解类时适配零手写)
11. 为什么 Wrapper? (AOP 织入 — Filter/Listener)
12. 为什么懒加载? (启动快 — 首次访问)
13. 为什么 3 目录? (优先级/兼容面)
14. 对照 Java SPI? (name 键 + 默认名 + 自适应)
15. 为什么异常缓存? (失败不重试)
16. 对照 Spring? (无循环依赖处理)

## 学生视角

17. 什么是 SPI? (服务提供接口)
18. 什么是扩展? (可插拔实现)
