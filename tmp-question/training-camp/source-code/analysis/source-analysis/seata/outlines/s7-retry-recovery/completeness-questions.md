# S-7 重试故障恢复 — completeness-questions (全视角提问验证)

## 开发者视角

1. 重试状态有哪些? (三系 14 态)
2. 重试怎么触发? (queueToRetry* → 状态)
3. 谁消费? (retry 线程池定时)
4. 多久重试? (1s 周期)
5. 什么时候放弃? (dead 阈值 70s)
6. 终态怎么定? (endRollbackFailed 三态)
7. 解锁? (默认不解锁, 人工)
8. MAX_RETRY_TIMEOUT? (-1 永不)

## 架构师视角

9. 为什么状态驱动? (状态即指令 — 重启可恢复)
10. 为什么默认永远重试? (最终一致优先 — dead 阈值兜底)
11. 为什么 70s/10s? (活事务 70s / 终态 10s 快速清理)
12. 为什么默认不解锁? (防误解锁 — 人工校准数据后解锁)
13. 为什么 DELAY_HANDLE_SESSION? (DB 模式防锁/分支残留)
14. 为什么动态延迟? (最早到期驱动 — 无会话低频)
15. 对照 RocketMQ? (固定周期 vs 延迟级别 — 无退避)
16. 为什么 retrying 参数? (重试与首次路径语义分离)

## 学生视角

17. 什么是重试? (失败后周期性再尝试)
18. 什么是死阈值? (重试终止时间 70s)
19. 什么是终态? (CommitFailed/RollbackFailed 等)
20. 什么是解锁? (释放全局锁, S-12)
