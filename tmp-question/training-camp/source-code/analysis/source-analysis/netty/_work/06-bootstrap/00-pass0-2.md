# Bootstrap — Pass 0-2

> 域: Bootstrap | 方案: B | 包: io.netty.bootstrap | 预估: 2 篇

## Pass 0-1

**继承树**: `AbstractBootstrap<B,C>` → `Bootstrap`(client) / `ServerBootstrap`(server)。`ServerBootstrapAcceptor` 是内部类 (ChannelInboundHandlerAdapter)。

**核心元素**: AbstractBootstrap.java 的 `bind()`→`initAndRegister()`→`init()`/`doBind0()` 组装链。ServerBootstrapAcceptor 的 `channelRead()` 分配 child Channel 到 childGroup。

## Pass 2 — 闭环笔记

**Q1: initAndRegister 组装链** — `channelFactory.newChannel()`→`init(channel)` (ServerBootstrap 重写: 设 childHandler 到 pipeline)→`config().group().register(channel)` (`AbstractBootstrap.java:324-354`)→`doBind0` 异步绑定 localAddress。5 个串联步骤，任意一步失败→forceClose。**设计决策**: `init()` 是 Template Method — ServerBootstrap 和 Bootstrap 的 init 完全不同。

**Q2: ServerBootstrapAcceptor** — `channelRead(ctx, msg)` (`ServerBootstrap.java:223-255`): `child.pipeline().addLast(childHandler)`→`setChannelOptions`→`childGroup.register(child)`。**关键**: `childGroup.register(child)` 返回 Future，Promise 连接是否成功 callback。failure → `forceClose`。autoread 延迟重开 (issue #1328)。

**Q3: Bootstrap vs ServerBootstrap** — `Bootstrap.connect()` 客户端的单连接。`ServerBootstrap.bind()` 服务端的 accept + child Channel。客户端的 handler 直接加到 pipeline；服务端 handler (server channel) vs childHandler (child channel) 分裂。`ChannelInitializer` + `ChannelInitializerExtension` 初始化钩子。
