## Pass 1: 扫描轮廓

### Netty 4.2 双轨架构

Netty 4.2 将 Netty 4.1 的 NioEventLoop 一分为二——EventLoop 处理任务调度与生命周期，IoHandler 处理实际的 I/O 操作（select / read / write）。这是一个关键的设计变更。

### 继承树

```
SingleThreadEventExecutor (common/)
  └── SingleThreadEventLoop (channel/)            — 任务调度 + 生命周期
        └── SingleThreadIoEventLoop (channel/)     — 关联 IoHandler，主循环体
              └── NioEventLoop (channel/nio/)      — NIO event loop (final)

MultithreadEventExecutorGroup (common/)
  └── MultithreadEventLoopGroup (channel/)         — EventLoop 组抽象
        └── MultiThreadIoEventLoopGroup (channel/)  — IoEventLoop 组
              └── NioEventLoopGroup (channel/nio/)  — NIO event loop group

=== I/O 操作链 (独立于 EventLoop 继承树) ===

IoHandler (channel/ — interface)                   — I/O 调度接口
  ├── initialize() → run(context) → destroy()
  ├── register(IoHandle) → IoRegistration
  └── isCompatible(Class) + wakeup()

NioIoHandler (channel/nio/ — final)                 — NIO 实现
  ├── Selector 管理 (open/rebuild/keySet优化)
  ├── SelectStrategy 决策 (CONTINUE/BUSY_WAIT/SELECT)
  └── processSelectedKeys (optimized/plain)

IoHandlerFactory (channel/ — interface)             — IoHandler 工厂
NioIoHandlerFactory (channel/nio/)                   — NIO 工厂
```

### 主循环体 (SingleThreadIoEventLoop.run())

```java
// SingleThreadIoEventLoop.java:192-205
protected void run() {
    ioHandler.initialize();
    do {
        runIo();                           // → ioHandler.run(context) = select + process
        if (isShuttingDown()) {
            ioHandler.prepareToDestroy();
        }
        runAllTasks(maxTaskProcessingQuantumNs);  // 处理任务队列
    } while (!confirmShutdown() && !canSuspend());
}
```

循环时序: I/O → 任务 → I/O → 任务 → ...

### NioIoHandler.run() — 核心 I/O 调度

```java
// NioIoHandler.java:419-496
public int run(IoHandlerContext context) {
    switch (selectStrategy.calculateStrategy(selectNowSupplier, !context.canBlock())) {
        case CONTINUE:  return 0;               // 有任务要运行，跳过 I/O
        case SELECT:    select(context, ...);   // 阻塞等待 I/O 事件
    }
    processSelectedKeys();                      // 处理就绪的 SelectionKey
}
```

### EventLoopGroup 分配策略

`NioEventLoopGroup` 继承 `MultiThreadIoEventLoopGroup` → `MultithreadEventLoopGroup`。`next()` 方法返回下一个 EventLoop——next 分配循环（round-robin 或 power-of-2 chooser）。
