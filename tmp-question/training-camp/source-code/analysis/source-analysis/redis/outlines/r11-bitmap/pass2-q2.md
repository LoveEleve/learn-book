# 闭环笔记 q2: redisBitpos — 字对齐跳过

## 假设
位定位 = 字对齐跳跃 (全 0/全 1 快速跳过) + 尾字 MSB 逐位扫描; 特殊值处理。

## 验证过程
- redisBitpos (bitops.c:80-165):
  - **字节对齐** (L98-109): 非字对齐前缀逐字节检查 (skipval = 找 0 ? 0xFF : 0x00)
  - **字跳跃** (L112-121): 整字跳过 (skipval = 找 0 ? ULONG_MAX : 0) — 大段连续位 O(1)/字
  - **尾字加载** (L130-138): 大端序字节组装 (MSB 优先, L123-129 注释)
  - **特殊值** (L140-145): 全 0 找 1 → -1 (L145, 无 1 位); 找 0 → 不返回 -1 (零填充假设, L76-78 注释)
  - **MSB 扫描** (L151-159): one 掩码从 MSB 移位逐位检查
- 应用: bitposCommand (L867) — BITPOS key bit [start [end [BYTE|BIT]]]

## 代码类型
Mechanism (位定位)

## 跨域关联
- R-24 (字符串) / R-1 (编码)

## 结论
bitpos = **"跳过不感兴趣的连续段"**: 找 1 时全 0 段整字跳过, 找 0 时全 1 段整字跳过 — 大位图稀疏场景 O(段数) 而非 O(位数)。MSB 优先位序与 SETBIT 一致。
