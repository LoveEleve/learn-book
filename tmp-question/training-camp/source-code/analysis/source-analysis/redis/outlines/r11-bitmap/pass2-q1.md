# 闭环笔记 q1: redisPopcount — 查表 + SWAR

## 假设
位计数 = 256 查表 + SWAR 28 字节批量 (每轮 7 个 uint32, 移位-加-掩码三阶段)。

## 验证过程
- redisPopcount (bitops.c:19-71):
  - **查表** (L23): bitsinbyte[256] 静态表 (每字节位数)
  - **对齐处理** (L26-29): 非 4 字节对齐前缀逐字节查表
  - **SWAR 批** (L33-66): 每轮 7 个 uint32 (28 字节) — 经典 SWAR 三阶段:
    1. `x - ((x>>1) & 0x55555555)` (L45: 每 2 位求和)
    2. `(x & 0x33333333) + ((x>>2) & 0x33333333)` (L46: 每 4 位求和)
    3. `((x + (x>>4)) & 0x0F0F0F0F) * 0x01010101 >> 24` (L59-65: 每 8 位求和 + 乘法累加)
  - 尾字节查表 (L68-69)
- 输入上限: 512MB+ (L17 注释, proto_max_bulk_len)

popcount = **查表 (对齐/尾部) + SWAR (主体)** — 28 字节/轮 ≈ 4 ops/字节, 比逐位快 ~10× (推断量级)。经典 SWAR 三阶段是面试考点。
