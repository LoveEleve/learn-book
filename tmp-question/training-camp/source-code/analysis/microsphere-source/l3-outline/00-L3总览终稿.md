## 〇、序言：这套大纲在教什么

**一句话**：L3 总教学大纲 = **"知识 + 现代实现 + 自主实现 + 线上落地"的完整闭环**——每个知识点不是"分析文档"，是四步走：**模式本体（是什么）→ 现代载体（官方源码锚定）→ my-xhs 判定（已用/该用没用/不该用——代码实证）→ 实验断言（能跑）**。

**三条主线贯穿 33 篇**：

1. **模式先于仓库**（L2 核心结论）——microsphere 14 仓 = 10 大复现模式在不同领域的实例化，**学 1 模式 = 懂多个仓库**（如 SPI 注册中心模式 = 11 个仓库）。
2. **JDK 演进吃掉框架模式**——每条"框架手写实现被 JDK 收编"都是知识本体与实现的分离（4.7/5.2 的替代图谱）。
3. **落地闭环**——my-xhs 每个判定都有代码实证（`mvn clean test` 140 断言 + 源码行号），"别人的东西只有自己重写一遍 + 上真线才算自己的"。

**阅读顺序**：先 §一 教学路径（6 阶段），再按维度索引逐章（每个维度索引是入口），每章末尾的"动手验证"是出口（实验全绿即通关）。
