# 维度二索引：分布式问题（Distributed Problems）

> 定位：**"分布式的麻烦长什么样"**——发现/配置/均衡/容错/事务/存储/网关/多活/可观测/消息 10 大问题域
> 文章：10 篇（08~17）| 实验：10 个模块（spec-discovery/config/loadbalancer/sentinel/tx/storage/gateway/zone/observability/event）
> 教学价值：**问题域教学主线**——每个问题 = 场景 + 模式 + 现代实现 + my-xhs 判定（本维度是"模式家族横向串联"的主战场）

---

## 一、维度定位

分布式问题维度是 L3 的**主体**（10 主题/10 问题域）——每个主题回答一个"分布式带来的麻烦"：服务怎么互相找（发现）、配置怎么变（配置）、流量怎么分（均衡）、坏了怎么办（容错）、跨库怎么一致（事务）、数据放哪（存储）、入口怎么收（网关）、机房挂了怎么活（多活）、怎么看得见（可观测）、怎么互相通知（消息）。
