## 1. 模板方法家族（模式 4——9/14 仓库）

### 极致案例：三层收敛（13 仓——491→13→2）

Druid 官方 Filter 的 **491 个方法**（全生命周期）→ 收敛成 **13 个** Statement 执行方法（final 强制路由）→ **2 个回调（2 回调）**（beforeExecute/afterExecute）：

```
适配器继承（FilterAdapter——491 空实现，只覆写关心的）
  → 13 个 final 方法（统一路由进 execute 模板——子类不可绕过）
  → 2 个抽象回调（子类最小实现）
```

**核心约束**：`final 路由`（子类不能绕过骨架——实验 `templateMethodForcesSkeleton` 验证骨架顺序）+ **子类最小实现**（只需覆写回调）。

**跨仓库实例**（每家族"1 主仓 + 实例表"）：

| 仓库 | 模板方法实例 |
|------|------------|
| 13 | 491→13→2 三层收敛（极致） |

## 2. 事件分发家族（模式 2——02 5.1 主落位）

**事件分发器**（02 5.1——2.10 章节的机制面）：

```
类型键缓存（ConcurrentMap<Class, List<Listener>>）
  + isAssignableFrom 继承匹配（父监听器接子事件——2.10 实验）
  + ConditionalEventListener 条件过滤
  + 写入时持锁重排（:199-207）
  + Executor 策略注入（direct/parallel）
```

**对照**：Spring 用 `ResolvableType` 精确匹配 vs microsphere 的 `isAssignableFrom` 宽松匹配——**精确 vs 宽松的匹配语义取舍**；配套 **SPI 自动加载**（监听器来源——4.3 交叉）。

## 3. 错误聚合家族（模式 10——07 5.2 主落位）

**InitializeErrors**（07——`ConcurrentHashMap + putIfAbsent`）：

```java
errors.putIfAbsent(key, error);   // 首错保留（并发安全——先到先得）
```

**"收集 + 聚合 + 首错保留"**是并行任务的标准错误处理（实验 `errorAggregationFirstWins` 验证）——**对比静默**（09 的 G15——"没报错的失败 = 事故伏笔"——2.9 交叉）。

**跨仓库实例**：07 并行子上下文（首错保留）/ 06 fast-fail 两种语义 / 09 G15 静默（反例）/ 14 高基数问题（2.4 交叉）。

> 可跳过（进阶级）：**元数据/编译期生成家族（模式 8——主落位）**——02 的 APT 三阶段闭环（注解 → 编译期 JSON → 运行期加载——1.1 章节机制）vs **10 的 Doclet**（命令元数据生成）——**两种编译期生成路径的对照**（APT 是注解处理器、Doclet 是 javadoc 钩子——09 的 G12 无版本号缺陷 vs 10 的 V0/V1 版本字节——元数据家族的教学本体）。

## 4. 过滤链与桥接家族（模式 7——12 仓主落位）

### ExecutorFilter 过滤链（12 1.1）

Executor 的 10 方法 default 族（update/query×2/queryCursor/commit/rollback/createCacheKey/deferLoad/getTransaction/close——**只覆写关心的**）+ **chain 参数显式传递**（Filter Chain 风格——实验 `explicitChainPassing` 验证：不调 proceed 则短路）+ Prioritized 排序 + InterceptingExecutor 包装。

**对照**：两种拦截模式——**显式 Chain**（12 的 ExecutorFilter）vs **隐式 Plugin 栈**（MyBatis-Plus）——"显式看得到链、隐式藏得深"。

### Interceptor 桥接（12 1.2）

**双体系适配**（InterceptorsExecutorFilterAdapter——MyBatis Interceptor ↔ ExecutorFilter）+ `@Intercepts` 签名解析（signatureMap）——**"两套扩展体系互相桥接"**（4.8 的桥接家族在 12 的实例）。

> **缺陷家族第 7 例（就近插入）**：`MyBatisConfigurationBeanDefintionRegistrar`（**Defintion 缺 i**——拼写错误家族第 7 例收官——StacKTrace/Pattens/FILER/Porperty/Cient/Comand 同族——4.5/4.7/4.8/2.10 已述——**API 稳定约束**：名字一旦发布就是契约）。

## 本章小结

**知识本体**：五家族本体——**模板方法**（final 路由 + 最小回调——491→13→2 极致案例）+ **事件分发**（类型键缓存 + 继承匹配 + 匹配语义取舍）+ **错误聚合**（putIfAbsent 首错保留——对比静默）+ **过滤链/桥接**（显式 Chain vs 隐式 Plugin + 双体系适配）+ **并发**（并行 + 错误聚合组合）。

**实验验证**：模板方法骨架 / 首错保留 / 显式责任链（3 断言）。

**my-xhs 判定**：模板方法该用没用（接口收敛模式可借鉴——适配大接口）/ 错误聚合已用（并行任务场景——2.5 实证）/ 过滤链该用没用（MP 拦截器体系覆盖——12 对照）。
