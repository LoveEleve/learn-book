> 定位：**"为什么"的层面**——CAP/BASE、共识算法、事务理论、多活理论

## 一、维度定位

理论维度与问题域维度（维度二）的区分：**问题域讲"怎么解决"，理论讲"为什么这样解决"**——CAP 解释为什么注册中心要 AP、共识算法解释为什么 ZooKeeper 能当协调者、事务理论解释为什么 Seata 比 2PC 好、多活理论解释为什么"同城双活"和"异地多活"不是一回事。
