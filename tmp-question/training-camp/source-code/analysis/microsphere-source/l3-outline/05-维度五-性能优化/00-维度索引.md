## 三、维度内知识主线（优化顺序方法论）

```
进程外（5.1 容器——Tomcat 参数见效最快）
  → 进程内（5.2 JVM——诊断/故障/演进——影响最深）
  → 网络层（5.3 Reactive——省线程/可预测扩展——架构级）
  → 数据层（5.4 连接池——复用/生命周期——最易被低估）
（stage-3-05 KP-01 三面顺序：容器参数见效快 → JVM 影响深 → 框架裁剪长期）
```
