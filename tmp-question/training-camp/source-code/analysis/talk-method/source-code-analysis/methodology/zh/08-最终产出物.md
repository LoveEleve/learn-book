## 每个阶段完成时必须存在的文件

### 规划阶段完成（交接给写作 AI 之前）

| 文件 | 内容 | 格式要求 |
|------|------|------|
| `00-domain-list.md` | 全量域清单 | 域#/路径/设计决策/面试/生产/Hub/置信度/依赖图/拓扑排序 |
| `01-book-plan.md` | 卷结构 | 每卷域数/🔴A/🟡B/核心问题/叙事连接 |
| `02-approach-selection.md` | 方案选择 | 每域 A/B/C/D 方案 + 理由 |

逐域产出：

| 文件 | 内容 | 格式要求 |
|------|------|------|
| `knowledge-planning/{卷}/{域}.md` | 知识规划 | 01逐源提取表 + 01聚合(P1/P2/P3) + 02深度分类(🔴🟡🟢) + 03聚类(依赖图+教学顺序) |
| `outlines/{域}/0N-{标题}.md` | Per-Article Outline | TOC 格式 + 教学叙事设计（场景开头→What→Why→How→总结收束）+ 跨层知识标注 [C++:/内核:/x86:] + 源码锚点 + 核心悬念 + OUTBOUND 桥 |
| `outlines/{卷}/{域}-pass1.md` | Pass 1 探索笔记 | 继承树/元素分解/≥5 标记问题 |
| 巨型域额外: `outlines/{卷}/{域}/01-{标题}.md` ~ `{N}-{标题}.md` | 逐篇独立大纲 | 每篇 TOC 格式 + 独立核心悬念 + 独立预估 |

全局：

| 文件 | 内容 |
|------|------|
| `HANDOFF.md` | 完整方法论文档 + 启动命令 + 已完成域清单 + 待重做域清单 |

### 写作阶段完成（最终交付）

| 文件 | 内容 |
|------|------|
| `articles/{卷}/{域}.md` | 完整文章 — 基于大纲写成、自然叙事、无 AI 模板 |
| `articles/{卷}/{域}/01-{标题}.md` ~ `{N}-{标题}.md` | 巨型域逐篇完整文章 |

## OpenJDK 项目的当前缺口

对照上述标准，OpenJDK 项目规划阶段的完成度：

| 文件 | 存在？ | 缺失 |
|------|:--:|------|
| `00-domain-list.md` | ✅ | — |
| `01-book-plan.md` | ✅ | — |
| `02-approach-selection.md` | ✅ | — |
| `knowledge-planning/**/*.md` | ❌ | **完全缺失** — 从未做逐源提取/聚合/分类/聚类 |
| `outlines/*/*.md` | ⚠️ 部分 | vol-01~03 大部分是早期薄域, 格式为叙事散文非 TOC |
| `outlines/*/*-pass1.md` | ⚠️ 部分 | vol-01~03 完全缺失, vol-04/06 有部分 |
| `HANDOFF.md` | ✅ | v13 方法论完整内联 |

**结论**: knowledge-planning/ 目录完全为空——这是 OpenJDK 项目最大的结构性缺口。
