# 方案选择决策树

> 角色：AI 自约束操作规范。开始每个域的分析前必读。
> 先修：`02-依赖顺序与分解原则.md` + `03-分析深度标准.md`
> 输入：域的优先级（🔴/🟡）来自 `progress/源码分析执行计划.md`
> 阅读顺序：01 → 02 → 03 → 04（本文）→ 05 → 06。完整执行顺序见 01。

## 核心问题

给定一个域，该用哪种分析策略？

## 四种方案

### A: 全深度

**通过**：0 → 1 → 2 → 3

**额外**：
- 时空溯源（checkout 早期版本，读 git diff 看演变）
- 极简复现（在 `harness/{framework}/` 构建微缩引擎）

**触发条件**：域是 🔴

### B: 标准

**通过**：0 → 1 → 2 → Pass 3（可选）

Pass 3 只在域有 ≥5 个标记问题值得合成完整叙事时执行。不够则止于 Pass 2 闭环笔记。注：01 的 ≥3 个闭环是 Pass 2 质量门槛，此处的 ≥5 是 Pass 3 资格检查——两个数字用途不同。

**额外**：无（不做时空溯源、不做极简复现）

**触发条件**：域是 🟡 且携带设计决策（03 标准）

### C: 浅层

**通过**：0 → 1 → 简略 Pass 2

简略 Pass 2：只答 1-2 个最关键标记问题，输出为简短闭环笔记，不合成叙事。其余标记问题标注为 `[trivial — skipped]` 并写一句简短理由。

**额外**：无

**触发条件**：域是 🟡 且机制简单（03 可跳信号：getter/委托/枚举/日志）

### D: 扫描

**通过**：简略 Pass 1（跳过标记问题和测试文件阅读）

产出：继承树 + 基本元素分解。不标记问题，不做深挖。

**额外**：写一段摘要描述该域在整体架构中的角色——足够跨域引用使用。

**触发条件**：纯胶水代码、薄封装、配置类、纯枚举

---

## 决策树

```
域是 🔴？
├── Yes → A: 全深度（强制：Pass 0-3 + 时空溯源 + 极简复现）
└── No  → 纯胶水/薄封装/配置/枚举？
           ├── Yes → D: 扫描（Pass 1 only + 架构摘要）
           └── No  → 携带设计决策？（03 标准）
                      ├── Yes → B: 标准（Pass 0-2，可选 Pass 3）
                      └── No  → C: 浅层（Pass 0-1 + 简略 Pass 2）
```

### 速查表

| 优先级 | 有设计决策？ | 方案 |
|--------|-------------|------|
| 🔴 | 任意 | A |
| 🟡 | 是 | B |
| 🟡 | 否（简单） | C |
| 🟡 | 胶水/枚举/封装 | D |

## 特殊情况

### Hub 升级

如果一个 🟡 域被 ≥10 个其他域依赖，从 B 升级到 A。此处理解不足的代价会级联扩散到大量下游域。

例外：如果 Hub 本身是薄封装（纯委托，无设计决策），输出升级标记但注明例外理由。

检查方法：`grep` 域名在 `progress/源码分析执行计划.md` 中——如果出现在 ≥10 条"前置依赖"行，标记 Hub 升级。

### 循环依赖

使用 `02-依赖顺序与分解原则.md` 的三轮策略，附加以下深度规则：

- **第一轮（各自浅扫）**：两个域都只做 Pass 0 + 简略 Pass 1（02 §1.4：仅继承树 + 元素分解，跳过标记问题和测试文件阅读）。不做 Pass 2。建立双方的基本概念——够命名它们之间的接口边界。
- **第二轮（交叉验证）**：对两个域联合执行 Pass 2。对第一轮的每一个标记问题，同时在两个域中 grep 和读源码。交叉验证接口约定、共享假设、交互点。

联合 Pass 2 产出：每个域独立的闭环笔记，但相关笔记引用对方域的源码位置。

- **第三轮（各自收尾）**：各自回归决策树判定的方案（A/B/C/D），如有 Pass 3 则完成。

### 叶子域

即使是 🟡，叶子域（零个下游依赖）是基础——最低 B，不能跳到 C/D，除非真的是薄封装。

## 方案选择产出

开始一个域前，输出此块：

```
## 方案选择：{域名}

优先级：{🔴/🟡}
方案：{A/B/C/D}
通过：{Pass 0→1→2→3 / Pass 0→1→2 / Pass 0→1 / Pass 1}
时空溯源：{是/否}
极简复现：{是/否}
需先分析的依赖：{从执行计划列出}

理由：[一句话——为什么选这个方案]
```
