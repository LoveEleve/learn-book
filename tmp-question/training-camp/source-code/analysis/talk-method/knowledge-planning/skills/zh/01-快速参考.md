## TOC 提取（01）

### 读 TOC 文件
```bash
# 列出主题下所有书的 TOC
find <topic-dir> -name "*.md" -type f

# 检查 TOC 深度（统计 2 级/3 级标题数）
grep -c "^## " <toc-file>     # 2 级（节）
grep -c "^### " <toc-file>    # 3 级（小节）
```

### 单书提取模板
```
## 知识点提取：{书名}

### 章节映射
| 原书章节 | 推断知识点 | 置信度 |
|---------|----------|--------|
| {章} {标题} | {概念} | {高/中/低} |
```

### 主题聚合模板
```
## 主题：{名称} — 跨书知识点聚合

分析书籍数：{N}

### 优先级1 — 共识（大多数书，>N/2）
- {知识点}（{书 §引用，书 §引用}）

### 优先级2 — 强信号（少数书，>1 但非大多数）
- {知识点}（{书 §引用}）

### 优先级3 — 孤立（仅 1 本书）
- {知识点} [待评估]（{书 §引用}）
```

## 深度分类（02）

### 判定三问
```
1. 面试频繁问到 或 生产环境常见？
2. ≥3 个其他知识点依赖它 且 偶尔遇到？
3. 书里提了吗？
```

### 逐知识点模板
```
## 深度决策：{知识点}

01 优先级：P1/P2/P3
重要性：🔴/🟡/🟢
理由：[1-2 句推理]
目标深度：表层/工作层/深层
书覆盖：充足/不足/仅主题方向/TOC 提及/未提及
AI 补充：是/否
```

### 主题汇总模板
```
## 深度汇总：{主题}

| 知识点 | 01 优先级 | 重要程度 | 深度 | 补充 |
|--------|----------|---------|------|------|
```

## 主题聚类（03）

### 依赖图格式
```
知识点：{名称}
  依赖：{概念} — {原因}
        {概念} — {原因}
        [BLOCKED — 主题 X 尚未完成]
  不依赖：{概念}
```

### 拓扑排序产出
```
## 教学顺序：{主题}

1. {叶子概念}（零依赖）
2. {下一个概念}（依赖 1）
3. ...
```

### 环形依赖
```
[与 #{编号} 环形 — 三轮策略]
```

## 跨书合并（04）

### 覆盖映射
```
| 书 | 覆盖度 | 角度 | 深度 |
|----|--------|------|------|
| {书名} §X | 充足/不足 | {角度} | 深层/工作层/表层 |
```

### 来源块
```
---
来源：
  主要：{书名} §{章节}（{覆盖度}）
  补充：{书名} §{章节} — {独特贡献}
  AI 补充：[{范围}] — {参考1}、{参考2}
  冲突：[{描述} — 或 "无"]
  缺口：[{缺口：{概念}} — 或 "无"]
---
```

## 统一标记

| 标记 | en | zh |
|------|-----|-----|
| 不确定性 | `[TODO: verify]` | `[待验证]` |
| 缺口 | `[Gap: {concept}]` | `[缺口：{概念}]` |
| 阻塞 | `[BLOCKED — Topic X not yet complete]` | `[BLOCKED — 主题 X 尚未完成]` |
| 未解决 | `[Unresolved: {声明 A} vs {声明 B}]` | `[未解决：{声明 A} vs {声明 B}]` |
| 环形 | `[CIRCULAR with #{编号}]` | `[与 #{编号} 环形]` |
| 单书 | `[N=1 — consensus signal unavailable]` | `[N=1 — 共识信号不可用]` |
