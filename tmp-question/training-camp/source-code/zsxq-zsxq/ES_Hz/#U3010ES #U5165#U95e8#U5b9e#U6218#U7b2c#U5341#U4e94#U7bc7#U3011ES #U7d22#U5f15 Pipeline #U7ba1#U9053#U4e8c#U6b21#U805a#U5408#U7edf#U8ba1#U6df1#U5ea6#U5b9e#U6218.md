**02 Pipeline 管道聚合基础知识**

在正式开始实战 Pipeline 聚合统计之前，我们先来了解下 Pipeline 聚合的基础知识。

## **2.1 Pipeline 管道聚合概念**

Pipeline 聚合是一种特殊的聚合，又称管道聚合，其独特之处在于：​它不直接对原始文档字段进行计算，而是以其他聚合的结果作为输入，进行「**二次聚合**」。

1.  每个数据聚合阶段是一个环节，多个环节串联一起来，形成一个管道模型，上一个环节的聚合结果是下一个环节的输入数据。
2.  基于Bucket分桶聚合，必须要有bucket分桶，且属于第一层级。
3.  二次聚合统计必须是数值类。

## **2.2 Pipeline 管道聚合与基础聚合的区别**

![](images/FgixeJj-K9-tOSnMy64G22WPpt3T.png)

## **2.3 Pipeline 管道聚合分类**

Pipeline 聚合分为两类：

1.  父级（Parent）Pipeline 聚合​：
2.  这类聚合的输出是将结果嵌入到现有聚合的结果桶中。
3.  为每个桶提供一个子聚合。
4.  ​示例​：avg\_bucket可以计算一个聚合中多个桶的平均值。它们计算的是同一父聚合下，相邻桶之间的变化。
5.  ​兄弟（Sibling） Pipeline 聚合​：
6.  这类聚合的输出是与现有聚合结果同级，会生成新的聚合结果。
7.  计算的是所有桶的总体指标。
8.  ​示例​：avg\_bucket（桶平均值），max\_bucket（桶最大值），stats\_bucket（桶统计信息）。max\_bucket可以找到另一个聚合中所有桶的最大值。

## **2.4 Pipeline 管道聚合执行流程**

![](images/FpfBrH1UEWDfMX247uHv-NB_rw8W.png)

1.  客户端发送请求​：客户端向Elasticsearch协调节点发送搜索请求，请求中包含管道聚合。
2.  ​协调节点接收请求​：协调节点解析请求，并将请求转发给索引的各个分片。
3.  ​分片执行本地聚合​：每个分片执行查询和基础聚合（如terms、date\_histogram等），但不会执行管道聚合。分片将基础聚合的结果返回给协调节点。
4.  ​协调节点合并分片结果​：协调节点合并来自各个分片的基础聚合结果。例如，对于terms聚合，协调节点会将相同term的桶合并。
5.  ​协调节点执行管道聚合​：在合并后的基础聚合结果上，协调节点执行管道聚合计算（如求导、平均桶等）。
6.  ​返回最终结果​：协调节点将最终结果返回给客户端。

关键点解析：​

1.  分层处理​：基础聚合在分片级别并行执行，Pipeline 聚合在协调节点串行执行。
2.  ​数据流向​：原始数据 → 分片基础聚合 → 协调节点合并 → Pipeline 计算。
3.  ​内存消耗​：Pipeline 聚合阶段所有桶数据需要在协调节点内存中处理。

  
![](images/Fse8m-7E8UrfdeZaZsfCINE-Ppz0.png)

上图展示了ES 中聚合查询的执行流程，特别是Pipeline聚合在整体聚合中的位置和依赖关系。

整体采用分层架构，从原始数据开始，经过多个层级的聚合处理，最终得到结果。强调了「**自底向上**」的执行顺序。

底层流程：

1.  起点：原始文档数据和聚合请求。
2.  Level 1: 叶子聚合（如date\_histogram、terms），负责对原始数据进行分桶，形成初始的桶集合。
3.  Level 2: 指标计算（如sum、avg、cardinality），对每个桶中的文档进行计算，得到每个桶的指标值。
4.  Level 3: 父级Pipeline聚合（如derivative、cumulative\_sum、bucket\_script），它们依赖于Level 2的指标计算结果，并在同一个父聚合的桶内进行二次计算。
5.  Level 4: 兄弟Pipeline聚合（如avg\_bucket、max\_bucket、bucket\_sort），它们对同一层级的所有桶的指标结果进行跨桶计算或排序。

关键点：

1.  执行顺序是自底向上：必须先完成叶子聚合和指标计算，才能进行Pipeline聚合。
2.  父级Pipeline聚合和兄弟Pipeline聚合的区别：父级Pipeline聚合的结果会嵌入到每个桶中，而兄弟Pipeline聚合会生成一个新的聚合结果。

## **2.5 Pipeline 管道聚合函数**

官方文档地址：[https://www.elastic.co/guide/en/elasticsearch/reference/8.17/search-aggregations-pipeline.html](https://www.elastic.co/guide/en/elasticsearch/reference/8.17/search-aggregations-pipeline.html)

![](images/Fg6qum_Q41Nm4DtQ4dDJ1HtahwVj.png)

1.  导数（Derivative）​​：计算一个聚合的导数。
2.  ​累积和（Cumulative Sum）​​：计算一个聚合的累积和。
3.  ​移动平均（Moving Average）​​：计算一个聚合的移动平均。
4.  ​桶脚本（Bucket Script）​​：对多个聚合的结果进行脚本运算。
5.  ​桶选择器（Bucket Selector）​​：根据脚本条件选择桶。
6.  ​平均桶（Average Bucket）​​：计算多个桶的平均值。
7.  ​最大桶（Max Bucket）​​：找到多个桶中的最大值。
8.  ​最小桶（Min Bucket）​​：找到多个桶中的最小值。
9.  ​总和桶（Sum Bucket）​​：计算多个桶的总和。
10.  ​统计桶（Stats Bucket）​​：计算多个桶的统计信息（最小值、最大值、平均值、总和、计数）。
11.  ​扩展统计桶（Extended Stats Bucket）​​：提供更多的统计信息（方差、标准差等）。
