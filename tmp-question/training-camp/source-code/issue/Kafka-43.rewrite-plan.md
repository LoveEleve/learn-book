# Kafka-43 重写规划

> 题目：一条请求的完整旅程——Kafka 服务端全流程串联
> 状态：全系列收束篇（对应 zsxq 服务端系列总结篇）；不做新专题，把 38+ 篇按一条请求路径串联。

## 1. 读者困惑
- 网络 → 请求处理 → 存储 → 响应怎么串起来？
- 幂等/事务在哪里插入这条链路？

## 2. 一句话顿悟
**一条请求经过 SocketServer 入口、KafkaApis 路由、ReplicaManager 存储、Purgatory 等待、最终 Processor 返回；幂等/事务在这条链路的追加校验点上叠加保护。**

## 3. 失败方案
- 各层独立理解但无法串联
- 把幂等/事务与网络层混同

## 4. 误解清单
- "响应在业务线程直接写回"：经过 responseQueue
- "幂等只在 producer"：broker 侧也校验

## 5. 证据清单
- 交叉引用 Kafka-13/14/7/9/28/10/33/35 等。

## 6. 版本边界与字数预算
- 基线 v4.x；目标 4000~6000 字。
