## 高优先级自补（学对应阶段前建议先补）

| 缺失内容 | 所属阶段 | 说明 |
|---------|---------|------|
| Spring Boot 3.x 迁移要点 | 阶段一 | 训练营代码基于 Spring Boot 2.x，需了解 javax→jakarta、AOT、虚拟线程 |
| 单元测试与集成测试规范 | 阶段一 | 训练营完全没有测试相关内容（segfault-lessons lesson-19 有测试示例可参考） |
| gRPC + Protobuf 入门 | 阶段三 | Stage3 #09-10 提了 gRPC 但无独立入门代码 |
| OAuth2 / OIDC / JWT | 阶段十一 | 训练营安全模块只讲了 RBAC 架构 |

## 中优先级自补（学完模块后巩固）

| 缺失内容 | 所属阶段 | 说明 |
|---------|---------|------|
| Saga 长事务编排 | 阶段四 | 训练营有两阶段、TCC、可靠事件，缺 Saga |
| 缓存一致性方案 | 阶段五 | 训练营讲了 LRU/布隆过滤器但缺 Cache-Aside/Write-Through |
| Redis Cluster 生产部署 | 阶段五 | 训练营讲了 Sentinel/Cluster 但没讲实际部署和故障演练 |
| Micrometer Tracing + OpenTelemetry | 阶段六 | 训练营基于 Sleuth（已过时），需补充现代方案 |
| K8s 实战教程 | 阶段九 | 训练营最薄弱环节，URL 指路 + 可编译模块速查 |
| GraalVM Native Image 实战 | 阶段八+十一 | **训练营只有 60 行提纲**。需自补：JIT vs AOT 区别、封闭世界假设、反射/代理配置、Spring AOT 处理。用 Spring Boot 3.x 编译一个 Native Image，对比冷启动和内存占用。 |
| 容器环境 JVM | 阶段十一 | CGroup 限制 / PID 1 信号 / OOM Killer |
