## 课程目标

1. 通过电商场景逐步从单体到云原生的全过程
2. 掌握互联网业务和系统架构演进过程
3. 系统地探讨技术和架构，兼顾广度和深度
4. 以工程视角掌握理论知识，不只懂概念
5. 解决"只闻其名，不知其貌"的困境

## 架构设计

训练营采用**三维一体**的架构方法论：

```
每个专题都从三个维度展开：
┌─────────────────────────────────────┐
│  应用管理端（怎么运维）              │
│  DevOps UI / 监控面板 / 配置管控台   │
├─────────────────────────────────────┤
│  应用服务端（怎么接）                │
│  业务代码整合基础设施 / 容器化部署   │
├─────────────────────────────────────┤
│  基础设施（怎么搭）                  │
│  Docker / K8s / Jenkins / 注册中心   │
└─────────────────────────────────────┘
```
