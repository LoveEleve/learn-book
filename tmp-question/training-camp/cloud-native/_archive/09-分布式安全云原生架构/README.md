# 09 分布式安全云原生架构

> 从 Java 安全底层（JAAS/JCA/JCE）到 Microsphere Security 认证授权框架，再到 Gateway 安全升级、DevOps 安全管理——全链路安全方案。

## 讲什么

### 基础设施

| 维度 | 内容 |
|------|------|
| Java | Java 安全架构（JAAS 认证/授权） |
| Java | Java 加密架构（JCA / JCE） |
| Java | Microsphere Security Web 安全：CSRF/CORS/Session 防护 |
| Java | Microsphere Security 认证与授权：RBAC 权限模型落地 |
| Java | Microsphere Gateway 安全架构升级（网关层统一鉴权） |

### 应用服务端

> 各服务整合 Microsphere Security 的认证授权。

### 应用管理端

| 维度 | 内容 |
|------|------|
| Java | Microsphere DevOps 安全管理（用户/角色/权限 Web 管控） |
| UI | DevOps UI 安全管理界面 |
