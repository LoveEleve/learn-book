## 04 聚类 — 4组 + 教学顺序

```
A (基础模型: CAP/一致性/时间/故障)
  │  3篇, 前置依赖: 无
  │  建立"网络不可靠→CAP推论→一致性定义→时间如何排序"的心智模型
  ▼
B (共识算法: Paxos→Raft→ZAB→EPaxos→变种)
  │  4篇, 依赖: A (已知故障模型+一致性)
  │  从"什么是共识"到"为什么有这么多算法"到"选哪个"
  ▼
C (分布式事务: 2PC→3PC→TCC→Saga→可靠消息→实战)
  │  3篇, 依赖: A+B (已知CAP+共识)
  │  共识在事务中的具体应用 + 源码实战
  ▼
D (协调与广播+案例分析: 选主/失败检测/广播/Google系统)
     2篇, 依赖: A+B+C (已知共识理论+事务)
     理论验证+工程回看 + 综合运用全栈知识
```

**教学顺序约束**:
- D依赖B(选主用Raft/Paxos) → D在B之后
- D依赖C(Google系统用事务) → D在C之后
- C依赖A(需要理解CAP) → C在A之后
- C依赖B(2PC/Paxos提交基于共识) → C在B之后
- B依赖A(共识需要理解故障模型/一致性) → B在A之后

**最终教学序**: A(1-3) → B(4-7) → C(8-10) → D(11-12)
